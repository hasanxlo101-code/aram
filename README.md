# KAyA Safe&Sec Academy | أكاديمية كايا للأمن والحماية الرقمية

منصة عربية متخصصة في التعليم العملي للأمن السيبراني، تحليل مراكز العمليات SOC، أمن تطبيقات الويب، التحقيقات الجنائية الرقمية DFIR، استخبارات المصادر المفتوحة OSINT، وأمن الذكاء الاصطناعي.

---

## 🚀 التشغيل السريع (Quick Start)

### المتطلبات المسبقة (Prerequisites)
- Node.js 22.12+ (يوصى بأحدث إصدار LTS متوافق مع Vite 8)
- npm أو bun أو yarn

### خطوات التثبيت والتشغيل المحلي
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

### النشر على Netlify
- `netlify.toml` يبني الواجهة إلى `dist` ويحوّل كل طلبات `/api/*` إلى الدالة `netlify/functions/api.ts` التي تشغّل نفس تطبيق Express الموجود في `server/app.ts`.
- مفاتيح الفحص اختيارية وتُضاف من Site settings → Environment variables (انظر `.env.example`). المصدر الذي لا يملك مفتاحًا يظهر في النتيجة «غير مفعّل» ولا تُختلق له نتيجة.
- `GET /api/health` يعرض المصادر المفعّلة دون كشف قيم المفاتيح.
- بعد تعديل الكود شغّل `npm run bundles` لإعادة توليد حزم ZIP في `public/` من الشيفرة الحالية.

### إعدادات الإنتاج
- انسخ `.env.example` إلى `.env` وضع مفتاح `GEMINI_API_KEY` في بيئة الخادم فقط إذا كنت تستخدم المرشد الذكي. لا تضف المفتاح إلى كود المتصفح أو المستودع.
- فعّل Firebase Authentication، وأنشئ حساب الإدارة المصرح به، وفعّل التحقق من البريد الإلكتروني. تسجيل دخول الإدارة يعتمد على Firebase وليس على `localStorage`.
- قيّد Firebase Web API key من Google Cloud Console إلى النطاقات وواجهات API المطلوبة. المفتاح الظاهر في تطبيق الويب ليس بديلًا عن قواعد Firestore الصحيحة.
- حدّ المعدل الموجود في خادم AI يعمل داخل العملية الحالية فقط؛ استخدم حماية موزعة من مزود الاستضافة عند تعدد النسخ.
- مستندات مكتبة الوثائق التي لا تملك `fileUrl` لن تُنشئ ملفات وهمية بامتدادات مضللة؛ أرفق الملفات الأصلية واربطها ببياناتها قبل إتاحتها للتنزيل.

## 📁 هيكلية المجلدات الرئيسية (Project Structure)

```
.
├── src/
│   ├── components/
│   │   ├── academy/          # المسارات الاحترافية الستة والمختبرات الموحدة
│   │   ├── courses/          # مقررات Word الـ 15 وعارض المستندات
│   │   ├── credentials/      # مصفوفة المهارات الرقمية ونظام الشهادات
│   │   ├── dashboard/        # لوحة المتدرب ونقاط الخبرة XP
│   │   ├── labs/             # محاكي الهجمات ومختبرات الـ Terminal
│   │   ├── library/          # مكتبة الوثائق الفنية وخطط الطوارئ
│   │   ├── projects/         # مشاريع التخرج النهائية ونماذج التقارير
│   │   └── security/         # درع الحماية وفاحص التهديدات
│   ├── data/                 # قواعد بيانات المسارات، الأسئلة، والمختبرات
│   ├── types/                # واجهات TypeScript المعيارية
│   └── utils/                # محرك الفحص الأمني والأدوات المساعدة
├── public/                   # الملفات الثابتة، الصور، وحزم التحميل ZIP
├── server.ts                 # خادم Express والوسائط المتعددة
├── firestore.rules           # قواعد حماية قاعدة بيانات Firestore
├── index.html                # نقطة الدخول ووسوم SEO و OpenGraph
└── package.json              # تبعيات المشروع
```
