# قائمة تحقق أمن تطبيقات الويب (مبنية على OWASP ASVS 4.0)
**أكاديمية KAyA Safe&Sec** · ملخّص عملي لأهم الضوابط. المرجع الكامل: https://owasp.org/www-project-application-security-verification-standard/

**طريقة الاستخدام:** ضع ✅ أو ❌ أو N/A لكل بند، وأرفق دليلًا (لقطة، اختبار، رابط كود). الحد الأدنى للتطبيقات العامة: المستوى 1، وللتطبيقات الحساسة (مالية/صحية): المستوى 2 فأعلى.

## V1 · البنية والتصميم
- [ ] نمذجة تهديدات موثّقة للميزات الحرجة (STRIDE).
- [ ] فصل المكونات وتقليل الامتيازات بين الخدمات وقاعدة البيانات.
- [ ] تحديد المستخدمين/الأدوار ومصفوفة الصلاحيات قبل التطوير.

## V2 · المصادقة
- [ ] كلمات مرور بطول ≥ 12 محرفًا، دون قواعد تعقيد قسرية، مع فحصها ضد قوائم التسريبات.
- [ ] تخزين كلمات المرور بخوارزمية مخصّصة: **Argon2id أو bcrypt أو scrypt** مع ملح فريد.
- [ ] دعم التحقق متعدد العوامل (يفضّل FIDO2/Passkeys) وإلزامه للإدارة.
- [ ] حماية ضد التخمين: تحديد معدل المحاولات وإشعار المستخدم بالدخول الغريب.
- [ ] استعادة الحساب بروابط أحادية الاستخدام قصيرة الصلاحية، دون كشف وجود الحساب.

## V3 · إدارة الجلسات
- [ ] رموز جلسة عشوائية طويلة (≥ 128 بت من CSPRNG) ويُعاد توليدها عند الدخول.
- [ ] كوكيز بخصائص `Secure; HttpOnly; SameSite=Lax/Strict`.
- [ ] إبطال الجلسة عند الخروج وتغيير كلمة المرور، ومهلة خمول مناسبة.
- [ ] حماية CSRF للطلبات المغيِّرة للحالة.

## V4 · التحكم في الوصول
- [ ] فرض الصلاحيات **على الخادم** في كل طلب (Deny by default).
- [ ] منع IDOR: التحقق أن المورد يعود للمستخدم الحالي، لا الاعتماد على المعرّف المرسل.
- [ ] فصل واجهات الإدارة وتقييد الوصول إليها.

## V5 · التحقق من المدخلات والترميز
- [ ] استعلامات مُجهّزة (Parameterized) لكل تعامل مع قواعد البيانات. لا دمج نصوص.
- [ ] ترميز المخرجات حسب السياق (HTML/JS/URL/CSS) لمنع XSS، واستخدام CSP.
- [ ] التحقق من المدخلات بقائمة سماح (Allow-list) ونوع وطول.
- [ ] حماية من حقن الأوامر وXXE وSSRF (قوائم سماح للوجهات).

## V6 · التشفير
- [ ] استخدام خوارزميات حديثة (AES-GCM، ChaCha20-Poly1305، SHA-256+، Ed25519).
- [ ] إدارة المفاتيح في خزنة/KMS، دون وضعها في الشيفرة أو المستودع.
- [ ] أرقام عشوائية من مولّد آمن تشفيريًا.

## V7 · الأخطاء والسجلات
- [ ] رسائل خطأ عامة للمستخدم دون Stack Trace أو تفاصيل داخلية.
- [ ] تسجيل أحداث المصادقة والصلاحيات وفشلها، دون تسجيل كلمات مرور أو رموز.
- [ ] حماية السجلات من التعديل والاحتفاظ بها زمنًا كافيًا.

## V8 · حماية البيانات
- [ ] تصنيف البيانات الحساسة وتقليل ما يُجمع ويُخزّن.
- [ ] منع تخزين البيانات الحساسة في الذاكرة المؤقتة للمتصفح (Cache-Control).
- [ ] تشفير البيانات الحساسة عند التخزين.

## V9 · الاتصالات
- [ ] TLS 1.2+ لكل الاتصالات مع HSTS، وشهادات صالحة.
- [ ] تعطيل البروتوكولات والشفرات الضعيفة.

## V10 · الشيفرة الخبيثة / سلسلة التوريد
- [ ] فحص التبعيات (SCA) وتحديثها، وتثبيت الإصدارات (Lockfile).
- [ ] مراجعة الشيفرة لوجود أبواب خلفية أو مفاتيح مضمّنة.
- [ ] استخدام Subresource Integrity للمكتبات الخارجية.

## V11 · منطق الأعمال
- [ ] حدود على العمليات الحساسة (معدلات، مبالغ) ومنع إعادة التشغيل (Replay).
- [ ] التحقق من تسلسل الخطوات في العمليات متعددة المراحل.

## V12 · الملفات والموارد
- [ ] التحقق من نوع الملفات المرفوعة ومحتواها وحجمها، وتخزينها خارج جذر الويب بأسماء مولّدة.
- [ ] منع تجاوز المسارات (Path Traversal) وتنفيذ الملفات المرفوعة.

## V13 · واجهات API
- [ ] مصادقة وتفويض لكل نقطة نهاية، وفحص أنواع المحتوى المقبولة.
- [ ] تحديد معدل الطلبات وحجم الجسم.
- [ ] عدم كشف بيانات زائدة في الاستجابات (Mass Assignment / Excessive Data Exposure).

## V14 · الإعدادات
- [ ] ترويسات أمان: CSP, HSTS, X-Content-Type-Options, frame-ancestors, Referrer-Policy.
- [ ] تعطيل وضع التطوير وصفحات الإدارة الافتراضية، وإخفاء إصدارات الخادم.
- [ ] فصل الأسرار والإعدادات حسب البيئة، وخطّ CI/CD محمي.
